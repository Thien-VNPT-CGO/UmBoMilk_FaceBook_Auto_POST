# Agent Workspace Rules

## Mandatory Auto GitHub Push Rule
- **CRITICAL REQUIREMENT**: After completing ANY code modification, bug fix, feature addition, styling update, or refactoring in this repository, you MUST AUTOMATICALLY run `git add .`, `git commit -m "..."`, and `git push origin main` to push the changes directly to GitHub!
- Do NOT ask for permission to push to GitHub. Always execute git push automatically at the end of every user request so Render continuously deploys the latest version!
